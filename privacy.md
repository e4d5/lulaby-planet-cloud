Privacy Policy — Lulaby Planet Cloud

Last updated: 19 November 2026

Lulaby Planet Cloud is operated by its developer for managing their own YouTube channels.

Google data access and use

With explicit authorization, the application accesses channel information, videos, playlists, video metadata and YouTube Analytics reports. It uses this information to prepare and manage uploads, schedule publication, assign videos to playlists and display statistics.

OAuth credentials are used to maintain authorized access to the selected channels.

Storage and sharing

Application records and OAuth credentials are stored locally on the operator’s computer and in local backups. Authorized requests are sent to Google to perform the selected operations.

Google user data is not sold, used for advertising or supplied to AI model providers.

This informational website is hosted on GitHub Pages. GitHub may process technical request information according to its own privacy statement.

Retention and deletion

Stored API data is refreshed or deleted according to applicable YouTube API requirements. Historical authorized statistics are retained only as permitted by those requirements.

The operator can remove local application data and credentials and must also manage any backup copies. Deleting local data does not delete videos or other content from YouTube.

Google authorization can be revoked at:
https://myaccount.google.com/permissions
