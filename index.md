Lulaby Planet Cloud

Lulaby Planet Cloud is a local desktop application for managing the developer’s own YouTube channels.

It supports preparing video titles and descriptions, uploading and scheduling videos, assigning videos to playlists, and viewing channel statistics through the YouTube Data API and YouTube Analytics API.

Google authorization is used to access channels selected by their owner. The application runs locally; this website provides information only and does not provide access to the application.
